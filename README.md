# Fortnite-Style Browser Battle Royale Game

A fan-made Fortnite-inspired browser survival game built with HTML, CSS, and JavaScript. This open source battle royale mini-game features an interactive island map, player movement, weapon pickups, shooting mechanics, enemy AI, health and shield systems, supply drops, eliminations, and victory conditions. Play directly in your web browser without installing a game engine.

## Install

1. Download or clone the project repository.
2. Make sure the following files are in the same project directory:
   - `index.html`
   - `style.css`
   - `game.js`
3. Open `index.html` in a modern web browser.
4. No build tools, package managers, or server configuration are required.

## Use

1. Open `index.html` in your browser.
2. Click **START MATCH** to begin playing.
3. Move around the island using WASD or the arrow keys.
4. Walk over weapons to collect them.
5. Aim using your mouse and click to shoot.
6. Press Space to shoot.
7. Find the red supply drop and approach it.
8. Press E to open the supply drop when you are close enough and have a weapon.
9. Eliminate all enemies to win the match.
10. Monitor your health, shield, ammunition, and eliminations in the sidebar.
11. Click **RESTART MATCH** to start over.

### Controls

- W / Arrow Up: Move up.
- S / Arrow Down: Move down.
- A / Arrow Left: Move left.
- D / Arrow Right: Move right.
- Mouse: Aim.
- Left Mouse Button: Shoot.
- Space: Shoot.
- E: Open the supply drop when nearby.
